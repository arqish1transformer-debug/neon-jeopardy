# Neon Jeopardy

A single-page Jeopardy game for social nights. Black background with neon text.

- **Present mode:** click a point value, show the answer, give or take points for each team.
- **Edit mode:** add questions, answers, pictures and videos, change point values, manage teams.
- Optional edit password (stored in the browser only, not real security).
- Full screen button (or press F).

Everything is saved in the browser you use, so set up and play on the same device.
Pictures and videos come from files on your device (videos under 80 MB).

## Run it

Open `index.html` in a browser, or host it free with GitHub Pages
(Settings > Pages > Deploy from a branch > main > / (root)).
The neon font loads from Google Fonts, so it needs an internet connection.
